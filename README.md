# Interactive Career Skill Map 🧠

An interactive roadmap platform that helps users explore, personalize, and track skill development using an AI-powered prediction engine. Designed to simplify career planning and visualize progress with a skill map.

## 🔧 Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **ML Engine**: Python (scikit-learn)

## ✨ Features

- Admin and Explore views for different user roles
- Visual representation of skills, subtopics, and resources
- Personalized skill recommendations using ML predictions
- LocalStorage integration for persistent user state
- Fully responsive design and smooth user experience

## 🤖 ML Prediction

- Python-based model using scikit-learn
- Input: Questionnaire data
- Output: Personalized skill suggestions
